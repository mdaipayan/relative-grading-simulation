# Bootstrap Reconciliation Note

## Purpose

This note records the relationship between the executable repository implementation and the bootstrap analyses used during manuscript development. It prevents an apparent discrepancy in bootstrap-resample counts or numerical intervals from being silently interpreted as a scientific-method change.

## Current executable implementation

The repository's `paired_bootstrap_ci` implementation uses **2,000 resamples by default**. The command-line statistical analysis script likewise defaults to 2,000 and permits the value to be changed with `--n-boot`.

The resulting `results/statistical_analysis/bootstrap.csv` is therefore the **current executable statistical output** for the repository's reproduced primary results.

## Frozen manuscript statistical record

The manuscript was frozen using the audited statistical workbook produced during manuscript development. Its reported primary bootstrap intervals are preserved explicitly in:

`results/statistical_analysis/bootstrap_manuscript_frozen.csv`

That archival table records the ten paired method contrasts, their frozen mean differences, the reported 95% paired bootstrap intervals, and the **5,000-resample** bootstrap setting used for those manuscript-development intervals.

## Why the two tables are retained

The current repository bootstrap table and the frozen manuscript table are **not numerically identical**. The difference is not explained by bootstrap resample count alone: the current executable reproduction also yields somewhat different paired mean contrasts because its reproduced cell-level outputs are a historical reproduction of the frozen simulation within the documented tolerances rather than a byte-for-byte copy of every historical analysis artifact.

Accordingly:

- `bootstrap_manuscript_frozen.csv` is the archival record of the bootstrap intervals reported by the frozen manuscript.
- `bootstrap.csv` is the output generated by the current executable statistical pipeline from the repository's current reproduced primary results.
- Neither table should be silently substituted for the other.
- The scientific estimand is unchanged: a paired confidence interval for method contrasts obtained by resampling experimental cells.

## Reproducibility interpretation

The repository claims **deterministic reproducibility of the current implementation** and **historical numerical reproduction within the tolerances specified in `config/reproducibility.yaml`**. It does not claim byte-for-byte reproduction of every historical manuscript-development table.

This distinction is intentional and is part of the release audit trail.

## Manuscript submission rule

The submitted manuscript remains the authoritative record for the final presentation of the study. If the manuscript is regenerated in a future software release, the new bootstrap intervals should be generated from that release and the manuscript values updated explicitly. No numerical replacement should be made silently.
